# 日英切り替えの共通化（Ctrl+Space トグル方式）

iPad / Android / mac / Windows に繋ぎ替えても、**同じキーで日本語⇔英語を切り替えられる**ようにするための設定まとめ。

## 方針

ZMK はつないだ先の OS を自動判別できないため、「OS ごとに出し分け」は原理的に不可能。
そこで **キーボードは全 OS 共通で `Ctrl+Space` を送る**ことに統一し、各 OS 側で `Ctrl+Space` を日英トグルとして受けるように設定する。

- 旧方式（`LANG1`=かな / `LANG2`=英数）は mac では完璧だが、Android が非対応で共通化できなかった。
- `Ctrl+Space` は mac / iPad / Android が標準対応。Windows だけ一度設定すれば対応する。

## キーボード側（ZMK）

`config/keymap.keymap` の layer_0 最下段・親指キー：

```
&mt LEFT_SHIFT LC(SPACE)   &mt RSHIFT LC(SPACE)
```

- **tap（軽く押す）** → `Ctrl+Space` = 日英トグル
- **hold（押しっぱなし）** → Shift（従来どおり）

左右どちらの親指キーでも切り替え可能。

## 各 OS で必要な設定

| OS | 追加設定 | 内容 |
|---|---|---|
| **macOS** | ほぼ不要 | デフォルトで `Ctrl+Space`＝入力ソース切替 |
| **iPadOS / iOS** | ほぼ不要 | デフォルトで `Ctrl+Space`＝次の入力ソース |
| **Android (Gboard)** | ほぼ不要 | `Ctrl+Space`＝言語切替に標準対応 |
| **Windows** | **要設定（1回）** | IME 側で `Ctrl+Space`＝IME オン/オフ を割り当て |

### macOS

1. 入力ソースに「**日本語（ローマ字入力）**」と「**ABC（英語）**」を追加
   - システム設定 → キーボード → テキスト入力 → 入力ソース → 編集 → ＋
2. 切替ショートカットの確認
   - システム設定 → キーボード → キーボードショートカット → 入力ソース
   - 「入力メニューの次のソースを選択」を `Ctrl+Space` に
3. `Ctrl+Space` が Spotlight と競合する場合は、Spotlight 側のショートカットを変更

### iPadOS / iOS

1. 設定 → 一般 → キーボード → キーボード で「**日本語（ローマ字）**」と「**English**」を追加
2. ハードウェアキーボード接続時、`Ctrl+Space` で次の入力ソースに切り替わる（追加設定ほぼ不要）

### Android（Gboard）

1. Gboard に「**日本語（ローマ字）**」と「**英語**」の言語を追加
   - 設定 → システム → 言語と入力 → 画面キーボード → Gboard → 言語
2. 物理キーボード接続時、`Ctrl+Space` で言語が切り替わる

### Windows（要設定・1回） ← 今回ハマったところ

Windows 標準の「新しい MS-IME」には任意キー割り当ての詳細メニューが**ない**ため、
「**以前のバージョンの Microsoft IME を使う**」を ON にしてから割り当てる。

1. 設定（Win+I）→ 時刻と言語 → 言語と地域
2. 「日本語」の **…** → 言語のオプション
3. 「Microsoft IME」の **…** → キーボード オプション
4. **全般** を開く
5. 一番下の「**以前のバージョンの Microsoft IME を使う**」を **ON**
6. タスクバーの「あ/A」を右クリック → **プロパティ** → 詳細設定
   → 編集操作の **キー設定「変更」** で `Ctrl+Space` に「**IME-オン/オフ**」を割り当て

> 複数の Windows マシンを使うなら、**Google 日本語入力**を入れて
> プロパティ → キー設定で `Ctrl+Space` を割り当てると、どのマシンでも同一 UI で設定でき、
> MS-IME のバージョン差に振り回されない。

## 注意点

- `Ctrl+Space` は**トグル**なので「今どちらの状態か」は画面の IME 表示で確認する。
- アプリによっては `Ctrl+Space`（補完など）と競合する場合がある。競合時は各 OS のショートカットを別キーに逃がす。
